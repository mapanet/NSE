# CONAPO — Municipal Population Projections

## 1. Overview

To update neighborhood-level demographic data beyond the 2020 Census, we rely on official municipal population projections published by CONAPO (Consejo Nacional de Población).    
These projections provide annual population estimates for every municipality in Mexico from 1990 to 2070.  

Because Mexico does not publish population projections at the AGEB, locality, or neighborhood level,   
the municipal projections are the only official source that can be used to update neighborhood-level population through proportional scaling.

This document explains:  

- What file we download
- What information it contains
- How we extract the required fields
- How we generate a clean TSV file for SQL Server
- How the data is used in AXSI’s demographic pipeline

### Description:

This CSV contains quinquennial population projections for every municipality in Mexico, broken down by:

- Entity (state)
- Municipality
- Sex (male/female)
- Year (1990–2070)
- Total population
- Population by age groups (0–4, 5–9, …, 85+)

**Important**

Each municipality appears twice per year:

- One row for HOMBRES
- One row for MUJERES

To obtain the total municipal population, both rows must be summed.

## 3. Relevant Fields

From the full CSV, we need only need:

| Field | Meaning |
| --- | --- |
| CLAVE | State (2 digts) + Municipality code (3 digits) |
| CLAVE_ENT | State code (2 digits) |
| NOM_ENT | State name |
| NOM_MUN | Municipality name |
| ANO | Year |
| POB_TOTAL | Total population for the given sex |

## 4. Years Required

- 2020 → Base population from the Census
- 2026 → Updated population using CONAPO projections

```phython
import pandas as pd

# Load original CONAPO file
df = pd.read_csv(r"D:\AXSI\CONAPO\Download\Proyeccion_Poblacion_2020_2030\pobproy_quinq1.csv")

# Filter only the years we need (2020–2026)
df = df[df["ANO"].isin([2020, 2021, 2022, 2023, 2024, 2025, 2026])]

# Zero-pad CLAVE_ENT (EE) and CLAVE (EEMMM)
df["CLAVE_ENT"] = df["CLAVE_ENT"].astype(str).str.zfill(2)
df["CLAVE"] = df["CLAVE"].astype(str).str.zfill(5)

# Compute CVE_MUN (right 3 digits of CLAVE → MMM)
df["CVE_MUN"] = df["CLAVE"].str[-3:]

# Group by municipality and year, sum male + female
df_total = df.groupby(
    ["CLAVE", "CLAVE_ENT", "NOM_ENT", "CVE_MUN", "NOM_MUN", "ANO"],
    as_index=False
)["POB_TOTAL"].sum()

# Rename columns for SQL Server compatibility
df_total.rename(columns={
    "CLAVE": "CVEGEO",      # EEMMM
    "CLAVE_ENT": "CVE_ENT", # EE
    "ANO": "ANIO",
    "POB_TOTAL": "POBLACION"
}, inplace=True)

# Export clean TSV
df_total.to_csv(r"D:\AXSI\CONAPO\conapo_municipal_2020_2026.tsv", sep="\t", index=False)

print("Generated: D:\\AXSI\\CONAPO\\conapo_municipal_2020_2026.tsv")
```
