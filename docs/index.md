# NSE Documentation — AMAI Socioeconomic Level for INEGI Neighborhoods

Welcome to the technical documentation for the **NSE (Nivel Socioeconómico AMAI)** pipeline developed by **mapanet / AXSI**.  
This documentation explains the datasets, methodology, SQL workflow, geospatial processing, and validation steps required to generate **Layer 6 — NSE by colonia** for all of México.

---

## 📘 What this documentation covers

- How AMAI NSE values are assigned to AGEBs  
- How INEGI MG 2025 geometries are processed  
- How INEGI DCAH 2025 neighborhood boundaries are normalized  
- How AGEB → colonia interpolation is performed  
- How NSE categories are computed  
- How final layers (1, 2, 5, 6) are generated  
- How geometry and territorial audits are executed  
- How the dataset is used in production (AXSI Real Estate)

---

## 📊 Official datasets

- **AMAI 2024** — NSE by AGEB  
- **INEGI MG 2025** — AGEB geometries  
- **INEGI DCAH 2025** — Neighborhood geometries  
- **INE 2025 Localities** — Rural fallback  
- **DENUE + OSM** — Optional enrichment for real estate analytics
